# GPPS_2026

Teaching notebooks for the Gaussian Processes Summer School:

- `gp_regression_rff_intro.ipynb` — Part 1: GP regression and random Fourier features.
- `gp_mixture_demo.ipynb` — Part 2: learnable Gaussian spectral mixtures.
- `gp_nf_spectral_demo.ipynb` — Part 3: normalizing-flow spectral distributions.
- `gp_implicit_spectral_demo.ipynb` — Part 4: implicit neural spectral samplers.
- `gp_gplvm_mnist_demo.ipynb` — Part 5: amortized variational GPLVMs for MNIST dimensionality reduction.
